Entry for the make.fun competition **Have You Tried Turning It Off?** — one funny line
a hopeless tech support agent says to a desperate customer.

`main.py` (stdlib only) writes the one-liner to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (default `output`).

The line twists the classic turn-it-off-and-on-again: the agent has already done
it himself, it did nothing, and he is cheerfully about to do it again anyway.
